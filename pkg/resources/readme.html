What you need for each game

Sky Recomp: your uncompressed Skyward Sword HD v1.0.0 files (romfs and exefs, no update) in a folder. Open the app, choose that folder, click Set up game files (a few minutes), then PLAY. Press Esc in the game for settings.

Mush8: one folder holding prod.keys, the base game .nsp, update 4.0.1 .nsp, your Firmware folder and optionally the Booster Course Pass .nsp. Open the app, choose the folder, click Prepare (a few minutes the first time).

Build Tears of the Kingdom: the base game 1.0.0 as .xci or .nsp, your prod.keys, optionally an update (1.1.2, 1.2.1 or 1.4.3). Needs macOS 26, Homebrew, an internet connection and about 25 GB free (40 GB with an update). The helper runs the build in Terminal and puts Tears of the Kingdom.app in Applications. Do not share that app: it contains the game.

First launch

The apps are signed without an Apple Developer certificate. If macOS refuses to open one, right-click it and choose Open, or allow it in System Settings > Privacy & Security.
